# قوالب التوثيق

## قرار معماري (ADR)
```
# ADR-NNN: <العنوان>
التاريخ: YYYY-MM-DD   الحالة: مقترح | معتمد | مُستبدل بـ ADR-XXX
السياق: <المشكلة/القيد — حقائق فقط>
الخيارات: 1) … 2) …
القرار: <اللي اتختار> — <ليه>
أثبتناه بإيه: <قياس/لقطة/اختبار>   |   لم نثبته: <…>
نطاق القرار: مشروع | عام
عواقب: <إيجابية/سلبية/ما ينكسر لو اتغيّر>
```

## سجل مشكلة وحل
```
# BUG-NNN: <وصف المرئي>
ظهرت: <فين/إزاي/على أي مقاس>   | أبلغ عنها: <المستخدم/اختبار>
الفرضية الأولى: <…>  → ثبتت؟ نعم/لا
السبب الجذري (مثبت بـ …): <…>
الإصلاح: <ملف/تغيير> (commit …)
تحقق: <اللقطة/القياس قبل وبعد>   | على الموقع الحي؟ نعم/لا
منع التكرار: <قاعدة/اختبار/checklist اتضاف>
```

## قالب ملاحظات مشروع (`projects/<name>/NOTES.md`)
```
# <المشروع>
مصادر: …   | تفضيلات صريحة: …   | قرارات تصميم: …
مناطق محمية: …   | سياسة الدمج: …   | روابط الحي/الإعلانات: …
ما تعلّمناه وقد يصلح للعام (مرشّح للترقية بعد مشروع ثانٍ): …
```

## تقرير نهائي للمستخدم (بالعربي)
1. ما اتغيّر (بالنتيجة المرئية)  2. السبب الجذري لكل مشكلة  3. الملفات  4. كيف اتختبر (ديسكتوب/موبايل/حي)
5. **ما لم أستطع التحقق منه**  6. المناطق المحمية سليمة؟ (دليل)  7. الباقي/المقترح التالي.
