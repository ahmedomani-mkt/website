# Checklists

كل بند قابل للتحقق (بقياس أو لقطة). لا تعلّم بند ✔ بدون دليل.

## 1) قبل ما أقول "تم" (أي تعديل واجهة)
- [ ] شغّلت `scripts/visual-qa.js` على **ديسكتوب 1440 وموبايل 390** (ومعه 461 لو في هيرو)، ونظرت للّقطات بنفسي
- [ ] لا horizontal overflow، لا صور مكسورة، لا أخطاء console (من تقرير السكربت)
- [ ] قائمة `clippedText` مراجعة يدويًا (كل بند: قص حقيقي أم false positive؟)
- [ ] scroll بـ wheel حقيقي (مش `scrollTo`) عدّى على كل الأقسام
- [ ] كروت/صفوف متكررة: قِستُ الأبعاد وهي متطابقة (اطبع `getBoundingClientRect`)
- [ ] CTA ظاهر كامل على الموبايل
- [ ] اختبرت ببيانات حقيقية (مش mock). لو استخدمت mock، شلتها وقلت كده
- [ ] المناطق المحمية في الـ brief لم تتغيّر (`git diff --stat` يؤكد)

## 2) نص عربي
- [ ] لا `letter-spacing` على عنصر فيه عربي
- [ ] نص متدرج/`background-clip:text` فيه padding رأسي
- [ ] أي حاوية `overflow:hidden` فيها نص: اتأكدت ما بتقصش الهمزة/التشكيل
- [ ] `dir="rtl"` و`lang="ar"`، وعناصر mono/لاتيني `direction:ltr` عند اللزوم
- [ ] لا كشيدة (ـــ) مكتوبة داخل نص محتوى

## 3) تعميم على الأسطح (بعد redesign)
- [ ] كل صفحات الموقع (فرعية/منتج/محتوى/404)
- [ ] لوحة التحكم (لو موجودة) + شاشة الدخول
- [ ] منيو الموبايل، الفوتر، النماذج، الـ modals
- [ ] الهيدر/الفوتر متطابقين (من مصدر واحد أو بسكربت مع diff للتأكد)

## 4) النشر والتحقق الحي
- [ ] الـ commit على الفرع الصحيح، الدمج حسب سياسة المشروع
- [ ] انتظرت ظهور **marker** من التعديل في الـ HTML/CSS المنشور (curl مع cache-bust)
- [ ] أعدت الاختبار على **الرابط الحي** (مش المحلي فقط)
- [ ] ذكرت في التقرير ما **لم** أستطع التحقق منه (لوحة التحكم المسجّلة، قاعدة البيانات، فيسبوك…)

## 5) تتبّع وإعلانات
- [ ] كل CTA (واتساب/اتصال/سلة) في **كل landing page** له حدث
- [ ] لا أحداث مكررة (دالة واحدة لكل حدث، ويتجاهل صفحات فيها معالج خاص)
- [ ] المعرّف مُعقَّم قبل الحقن، والـ CSP يسمح بالنطاقات المطلوبة
- [ ] وضع استبعاد المالك شغّال
- [ ] قلت للمستخدم يختبر في Test Events (أنا مش قادر أرى سيرفر فيسبوك)

## 6) ممنوعات الادعاء
- لا "تم النشر" بدون marker حي. لا "الاختبارات نجحت" بدون مخرجات. لا "Live" لو مش live فعلًا.
