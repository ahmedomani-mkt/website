# تقرير التحقق المستقل (2026-10-17)

## ما اتأكد منه بأدلة
| البند | كيف | النتيجة |
|---|---|---|
| صيغة الـ Skills والـ rules والـ CLAUDE.md | وثائق Claude Code الرسمية (`code.claude.com/docs/en/skills` و`/memory`) | متوافقة: SKILL.md + frontmatter (`name`,`description`,`disable-model-invocation`)، `paths:` في الـ rules، CLAUDE.md < 200 سطر، ملفات مرافقة داخل مجلد الـ skill ومرجعها `${CLAUDE_SKILL_DIR}` |
| اكتشاف الـ Skills | `claude -p --output-format stream-json` داخل مجلد معزول: قائمة `skills` في رسالة الـ init | الـ 7 ظهروا (v1) |
| الاستدعاء التلقائي | 5 جولات `claude -p` | **v1: 0 استدعاء في كل الجولات** (حتى بدون الـ kit). بعد إضافة Workflow triggers في CLAUDE.md: **استدعى `brief-to-requirements` في الجولتين (2/2)** |
| الاستدعاء اليدوي `/visual-qa` | جولة معزولة | اشتغل، شغّل السكربت المرفق، التزم بمكان المخرجات ونضّف وراه |
| خطة قبل الكود | الجولة الأخيرة | طبعت متطلبات + محمي + معايير قبول + افتراضات **قبل** أول ملف |
| الاختبار الفعلي والإصلاح وإعادة التحقق | جولات مع/بدون kit | مع الـ kit (جولة الكروت): قاس، أصلح، لقى عيب إضافي على الموبايل، أصلحه وأعاد القياس. بدون kit: عدّل بالقراءة فقط وقال إنه لم يختبر (صادق، لكن لم يجد Playwright) |
| الصدق في التقرير | كل الجولات | كل التقارير فرّقت بين المختبَر وغير المختبَر (المطلوب كان في الطلب نفسه أيضًا) |
| فحص مستقل لمخرجات الجولة الأخيرة | بنفسي: curl على الـ API + `visual-qa.js` على 1440 و390 + لقطة | الصفحة 200، validation يرد 422، لا overflow ولا صور مكسورة ولا أخطاء |

## حدود الاختبار (لا تُقرأ كنجاح أكبر مما هو)
- **n=1 لكل حالة** والنموذج غير حتمي. الفروق بين الجولات مؤشر، مش إثبات إحصائي.
- الاختبار **headless**: ما اختبرتش التوقف لموافقتك على الخطة (في الجلسة التفاعلية)، ولا الـ hooks.
- مجموعة الضبط (بدون kit) اتأثرت بالبيئة: ما لقتش Playwright بينما الـ kit قدّم مساره. فجزء من الفارق **بيئي** (مسار المتصفح مكتوب كاحتياطي في السكربت) مش منهجي بحت.
- ما اختبرتش: `disable-model-invocation` عمليًا (اعتمدت على الوثائق)، تحميل rules المقيّدة بـ `paths` (الجولات قرأتها بنفسها بـ cat، فمش دليل على التحميل التلقائي)، التوافق مع إصدارات أقدم من Claude Code (جُرّب على 2.1.302)، الاستخدام على مشروع غير صفحات HTML.
- الاختبارات كانت على تطبيق صغير (نموذج RTL)، مش تطبيق متعدد الصفحات أو بقاعدة بيانات.
- الجولات المعزولة شافت تذكير مهام من جلستي (تسريب بيئي)؛ تجاهلته ولم يؤثر على الناتج الظاهر.
